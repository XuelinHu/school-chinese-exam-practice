软件名称：面向马来西亚留学生的汉语练习平台V1.0
版本号：V1.0
开发的硬件环境：Linux 本地开发服务器或普通 PC 工作站，建议 4 核 CPU、16GB 内存、固态硬盘，能够同时运行 Node.js、MySQL、Chromium 和 PDF 导出工具。
运行的硬件环境：Linux/Windows 应用服务器或教学管理终端，建议 2 核 CPU、4GB 内存、20GB 可用磁盘空间；用户通过浏览器或 H5 页面访问。
开发该软件的操作系统：Linux
软件开发环境 / 开发工具：Node.js、npm、Express、Vue/Vite 或静态 H5、MySQL、Chromium、命令行终端、Git。
该软件的运行平台 / 操作系统：浏览器 Web/H5 应用，后端运行于 Node.js，数据库运行于 MySQL。
软件运行支撑环境 / 支持软件：Node.js、MySQL、现代浏览器、静态资源服务、JSON API 服务。
编程语言：JavaScript、Vue、HTML、CSS、SQL、Node.js 脚本。
源程序量：本次源码稿选入 39 个真实源码、配置、SQL 或脚本文件，不包含第三方依赖、构建产物、截图和 PDF。
开发目的：中国与马来西亚人文交流源远流长，是东盟教育合作的重点伙伴国家。近年来，依托中国—东盟教育交流周、千校携手计划、双向留学互通等合作机制，中马高校校际合作、学生交换、联合培养项目持续增多，马来西亚来华留学生规模逐年攀升，涵盖本科、硕士、交换生等多个培养层次，是东南亚来华留学的核心生源群体之一。随着双边经贸、文化、教育合作不断深化，汉语能力已成为马来西亚留学生学业深造、校企实习、跨境就业的核心必备能力。现阶段，马来西亚留学生汉语学习存在明显的适配性短板。市面通用汉语学习平台多为通用型教学模式，缺乏针对马来西亚留学生母语习惯、汉语学习难点、考试考点的定制化练习内容，且贴合来华留学日常学习、校园生活、学术交流的专项练习资源匮乏。多数留学生存在口语应用薄弱、应试能力不足、场景化汉语运用不熟练等问题，传统线下课堂练习、纸质习题模式形式单一、反馈滞后，无法满足碎片化、常态化、个性化的汉语提升需求。为精准适配马来西亚留学生的汉语学习特点，聚焦日常交流、学业考试、学术应用等核心场景，搭建专项化、智能化、轻量化的线上练习平台，弥补现有学习资源的短板，帮助留学生高效提升汉语综合能力，适配中马教育双向交流的发展趋势，助力更多马来西亚留学生顺利完成学业、深化中马人文互通，特此开发本汉语练习平台。
面向行业 / 领域：教育信息化、国际留学生服务、在线学习与教学管理。
软件的主要功能：认证与资料模块面向学生、管理员，提供注册、登录、个人资料查询和更新，主要通过/api/auth/*实现，并围绕users等数据对象完成业务处理。练习资源模块面向学生，提供等级、分类、试卷列表和试卷详情查询，主要通过/api/learning/*实现，并围绕levels、question_categories、papers、questions等数据对象完成业务处理。在线答题模块面向学生，提供试卷答题、提交判分、答案记录和错题写入，主要通过/api/learning/papers/:id/submit实现，并围绕study_records、user_answers、wrong_questions等数据对象完成业务处理。错题本模块面向学生，提供个人错题列表、错误次数和解析查看，主要通过/api/learning/wrong-questions实现，并围绕wrong_questions等数据对象完成业务处理。学习记录模块面向学生、管理员，提供个人成绩记录和管理端全量成绩记录，主要通过/api/learning/records、/api/admin/records实现，并围绕study_records等数据对象完成业务处理。后台统计模块面向管理员，提供学生数、题目数、试卷数、记录数和平均分统计，主要通过/api/admin/stats实现，并围绕users、questions、papers、study_records等数据对象完成业务处理。系统支持用户在真实运行页面中完成登录、查看、查询、提交、统计或管理操作，并通过后台接口和数据库实现数据保存、权限限制、业务结果返回和运行检查。本次软著材料重新采集了 H5 竖屏校准截图和桌面管理截图，能够证明页面真实可运行、业务数据真实加载、核心流程可交互。
软件的技术特点：系统采用浏览器前端、Node.js/Express 后端和 MySQL 数据库的分层结构，前端负责页面渲染、语言切换、表单交互和请求发起，后端负责认证鉴权、角色控制、业务接口、数据查询和异常处理，数据库保存用户、角色、业务主数据、记录数据和统计数据。系统支持本机 Linux 环境部署，截图和 PDF 导出阶段通过本机回环地址访问本地服务，敏感配置在文档和源码稿中统一脱敏。
